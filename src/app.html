资料方案

只投一类岗位就用默认这一套。要投几类岗位（经历写法、简历文件不同），各复制一套。下面编辑的都是选中的这一套。

导入简历

把简历内容整理进资料，省得一项项填。也可以跳过，直接往下填。

用插件自带的 AI 整理

选一份「文档」里的 PDF，交给 AI 整理，几十秒就好，整理完不保存。

还没有 PDF 简历，先到「文档」上传一份。

用你自己的 AI 整理

在 ChatGPT 或 Claude 里上传简历 PDF，粘贴提示词发送，再把返回的内容粘贴到这里。

提示词不含你的个人信息。

导入后往下检查一遍。换了新简历可以再导入一次：证件号、账号密码这些你自己填的不会丢。

简历和照片

遇到上传简历、上传照片的地方会自动传上去。简历 PDF 在顶部的「文档」里上传和管理，这里选这套资料用哪一份。

自动填写

打开后，进入任何网页都会直接填好认得的表单，翻到下一步也会接着填。关闭后只在你点扩展图标里的「填写当前页面」时才填。不投简历时建议关掉。

在线更新岗位

「岗位」里的数据来自各大厂招聘官网的公开岗位，每天更新一次。打开后，进入「岗位」时如果本机的数据超过一天，就下载新的一份：只下载公开岗位数据，不上传任何东西，不带你的资料、账号或任何标识。默认打开；关掉后「岗位」里只显示以前下载过的数据。

数据来自投简历神器的服务器（转发 GitHub 上 HideInSky/resume-autofill 每天更新的那份）。

AI 设置

匹配打分、回答表单里的开放问题时用

用你自己的 Claude 订阅，不花 API 额度。要在电脑上装好 Claude Code：

  1. 在终端里进入扩展的 agent 文件夹，运行 npm install
  2. 运行 claude mcp add toujianli -- node <agent 文件夹的完整路径>/server.mjs
  3. 把 agent/commands/autopilot.md 复制到 ~/.claude/commands/
  4. 打开 Claude Code，输入 /autopilot，让它一直开着
