# 投简历神器 Resume Autofill

一个**只在本地运行、完全开源**的 Chrome 扩展：把简历资料和简历文件存在自己的浏览器里，投简历时一键（或一打开页面就自动）填进网申表单、传上简历。

做这个的原因很简单：市面上的"一键填简历"工具大多要你注册账号、把整份简历（甚至身份证号）传到它们的服务器。这个扩展不需要账号，没有服务器，也不联网。

## 隐私设计（都可以自己核对）

| 承诺 | 怎么核对 |
| --- | --- |
| 不发送任何网络请求 | [manifest.json](manifest.json) 的 CSP 写死了 `connect-src 'none'`；全部源码里搜不到 `fetch` / `XMLHttpRequest` / `WebSocket` |
| 默认看不到任何网页 | 只申请 `activeTab`：只有你点击「一键填写」的那一刻，才能访问当前这一个标签页 |
| 自动填写由你开关 | 打开自动填写 = 给扩展访问网页的权限；关掉就收回，扩展又碰不到任何网页。侧边栏和资料页都有这个开关 |
| 资料只存在本机 | 只用 `chrome.storage.local`（明文，和浏览器保存的其他数据一样受系统账户保护），不用会同步到云端的 `storage.sync` |
| 不替你提交 | 只填值、选选项、传文件，不点「保存」「提交」「注册」；填过的字段用绿框标出 |
| 密码可以不进页面 | 关掉「填写密码框」后，网申密码根本不会被传给页面脚本 |
| 没有第三方依赖 | 纯原生 JS，没有构建步骤 |

## 安装

1. 下载或 `git clone` 本仓库
2. Chrome 打开 `chrome://extensions`，右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本文件夹（含 `manifest.json` 的那一层）

Edge、Brave、Arc 等 Chromium 浏览器同理。更新代码后在 `chrome://extensions` 点一下刷新。

## 使用

1. 点扩展图标 →「去填写我的资料」，按页面从上到下做：让 AI 从简历 PDF 导入（或手填）→ 检查补全 → 添加简历文件和照片 → 打开自动填写
2. 打开网申页面，点扩展图标（或 `Alt+Shift+F`），侧边栏会在网页旁边打开 →「填写当前页面」。侧边栏里列出填好了哪些、还差哪些，点一项就滚到页面上对应的位置
3. 想省掉点击：在侧边栏「设置」里勾选「打开网页时自动填写」，之后打开任何网页都会直接填好，翻到下一步、展开新的段落也会接着填。**不投简历时建议关掉**——打开期间任何网页上带「手机」「邮箱」「密码」字样的输入框都会被填上
4. 检查绿框标出的内容，补上没认出来的，自己点保存 / 提交

### 能填什么

- 普通输入框、多行文本、原生下拉框、单选框
- **网站自己画的下拉框**（点开才出选项的那种，包括学校 / 专业这类要输入关键字搜索的，以及国家 / 省 / 市三连下拉）
- 日期输入框
- **上传简历和照片**：上传框旁边写着「简历」「照片」的会自动传；已经有文件的不会重复传
- 手机区号、证件类型、籍贯、民族、意向城市等选择项

### 其他功能

- **让 AI 帮你填资料**：资料页点「复制提示词」，连同简历 PDF 发给 ChatGPT / Claude，把它返回的 JSON 粘贴回来导入即可。提示词和模板由字段定义自动生成；扩展自己仍然不联网，简历给哪个 AI 由你决定
- **多套资料方案**：不同类别的岗位各建一套，各有自己的求职意向、经历描述和上传用的简历文件。自动填写用默认方案；某个页面要用另一套，在侧边栏里切换，会按新的那套把这个页面重填一遍。可以同时开多个标签页，各用各的方案
- **网申账号**：保存注册 / 登录各家网申系统用的用户名和密码，遇到账号框、密码框就填（可在侧边栏或资料页关掉密码）
- **常见的是 / 否题**：是否接受工作地变更、是否服从调剂、是否学生干部、是否国家重点实验室、学制、语言熟练程度 / 证书 / 成绩等都是资料里的固定项；「是否有亲属在本公司任职」不填时默认选「否」
- **自定义字段**：资料表里还没有的问题，用「关键词 → 内容」自己加，下拉和单选也适用
- **投递记录**：网申页面上填好了教育和工作经历，右下角会问要不要记到投递记录；你自己点了「投递 / 提交」会提示「恭喜完成一份投递」并自动记下。在侧边栏「资料」里点「投递记录」打开看板（收藏 / 已投递 / 面试中 / Offer / 已结束），卡片拖到别的列就是改状态。可以连到一个本地 CSV 文件，用 Excel 打开
- **文档**：上传、查看、删除简历 PDF，网格或列表显示，可以多选删除；每套资料选一份用来上传
- **点击复制**：自动填不上的字段，在侧边栏的「资料」标签页里点一下就复制。侧边栏一直开在网页旁边，可以连续复制好几项
- **导入 / 导出**：JSON 备份，换电脑时用（导出文件是明文，自己保管好）

## 已知局限

- 字段靠标题文字的关键词识别，下拉框靠"点开 → 找文字相同的选项 → 点它"。不同网站写法五花八门，难免有认错或漏掉的。**保存 / 提交前务必自己检查一遍**
- 日期选择器是直接把日期写进输入框，个别只能用鼠标点选的日历可能不认
- 多段经历按资料里的顺序依次填入表单的第 1、2、3… 段；段数不够时不会替你点「添加」
- 没有输入框、完全用 `div` 画的下拉框，以及复选框，暂不支持

## 让它认识更多字段

所有字段和关键词都在 [src/schema.js](src/schema.js) 里，每个字段一行，例如：

```js
f('phone', '手机号', /手机|电话|联系方式|phone|mobile|\btel\b|cell/, { only: 'text' }),
```

遇到没认出来的字段，把那个网站的叫法加进正则就行。下拉选项的同义词（如「硕士」↔「Master」、「美国」↔「United States」）在 [src/filler.js](src/filler.js) 开头的 `SYNONYMS` 里。欢迎提 PR。

## 开发与测试

没有构建步骤。两张测试页都带自检脚本，全部是虚构数据：

- [test/form.html](test/form.html)：普通表单，中英文常见字段
- [test/aui.html](test/aui.html)：仿国内网申系统的自定义组件（弹出式下拉、三连地区、无 name 单选、隐藏的上传 input）

```bash
python3 -m http.server 8765
```

然后打开 <http://localhost:8765/test/form.html> 和 <http://localhost:8765/test/aui.html>，页面顶部会显示通过了多少项。

## 文件结构

```
manifest.json       扩展清单（权限、CSP）
src/schema.js       字段定义和识别关键词
src/filler.js       填表引擎（注入页面执行）
src/vault.js        本地存储
src/run.js          把资料送进页面（侧边栏和后台共用）
src/background.js   后台：自动填写的调度
src/auto.js         在已开启的网站上发现新表单时通知后台
src/app.html        主页面：我的资料 / 投递记录 / 文档（顶部导航切换）
src/options.js      我的资料
src/tracker.js      投递记录看板
src/documents.js    文档
src/panel.*         侧边栏（填写清单、点击复制）
src/apps.js         投递记录的存取和 CSV
icons/              图标（scripts/icons.py 生成）
scripts/pack.sh     打包成上架用的 zip
docs/PUBLISH.md     上架 Chrome 应用商店的步骤
test/               测试页
```
